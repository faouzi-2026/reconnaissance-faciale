# Contrôle d'Accès Intelligent aux Infrastructures Sportives

Projet de Fin d'Études (PFE) portant sur l'optimisation de la robustesse des algorithmes de reconnaissance faciale (FaceNet, ArcFace, AdaFace) via l'**Embedding Stability Index (ESI)**.
## Contenu du dépôt
- `app.py` : Application interactive Streamlit (Chapitre 9).
- `requirements.txt` : Dépendances Python nécessaires pour le déploiement.
